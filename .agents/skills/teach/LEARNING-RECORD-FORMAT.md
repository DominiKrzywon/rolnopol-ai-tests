# Learning insight format

```md
### LR-0001: {Short title of what was learned or established}

{One to three sentences stating the insight or claimed prior knowledge,
its depth, and why it changes future teaching.}
```

In Rolnopol, append these entries to NOTES.md and increment the highest existing
LR number. In a standalone teaching workspace, use `learning-records/0001-slug.md`,
increment the highest filename number, and use a level-one title instead.
Create that directory only when writing the first record.

Record demonstrated understanding, disclosed prior knowledge, corrected
misconceptions, or confirmed mission changes. Distinguish self-report from an
observed successful exercise. Covered material and ordinary session activity do
not qualify. Definitions belong in the glossary rather than duplicated records.

Optional details, only when useful:

- **Evidence:** the answer, exercise, or self-report supporting the insight.
- **Implications:** what this unlocks or rules out for later lessons.
- **Status:** `active` or `superseded by LR-NNNN`.

When an insight is replaced, retain it with a superseded status and create the
replacement entry. For a mission shift, link to MISSION.md using a relative
Markdown link appropriate to the record's actual location.
