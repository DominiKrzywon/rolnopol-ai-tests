# Short skill template

The following block is a template to adapt, not another installed skill.

```markdown
---
name: task-name
description: 'A concrete action and the situation in which to select this skill.'
---

# Task name

Apply the [shared context](../CONTEXT.md).

## Workflow

1. Read the sources needed for the task.
2. Make the decision specific to this workflow.
3. Complete the work within the user's requested scope.
4. Select verification and report the evidence.

## Done

State the observable outcome and verification limitations.
```

The template link is correct when placed in SKILL.md inside a directory directly
under the skills directory. Do not copy the steps without adapting them to a real task.
